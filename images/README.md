# Images Folder

This folder should contain the following images for the Graduate Job Connect website:

## Required Images:
1. **graduate1.jpg** - Hero section image (main graduate image)
2. **graduate2.jpg** - Graduate card image 
3. **company1.jpg** - Employer card image
4. **company2.jpg** - Additional company image (for future use)

## Image Specifications:
- **Format**: JPG or PNG
- **Size**: Recommended 800x600px or similar aspect ratio
- **Content**: Professional photos related to:
  - Graduates: Young professionals, graduation ceremonies, job interviews
  - Companies: Office environments, team meetings, corporate buildings

## Usage:
- These images are referenced in the CSS and HTML files
- Make sure the file names match exactly as specified above
- Images should be professional and high-quality

## Placeholder Note:

- Unsplash.com (free professional photos)
